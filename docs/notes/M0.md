## Findings

- **ragas 0.4.3 breaks against langchain-community 0.4.x.** `ragas.llms.base` imports
  `langchain_community.chat_models.vertexai`, which 0.4 removed. `pyproject.toml` pins
  `langchain-community<0.4` in the `eval` extra. Drop the pin when a ragas release stops importing it.
- **`docker compose up --wait` does not wait for one-shot containers.** The compose file has no
  model-pull service. `OllamaEmbedder.ensure_model()` pulls on first use instead, so `config/lab.yaml`
  is the only place a model is named.
- **No NVIDIA runtime in the local Docker (Rancher Desktop).** Ollama runs on CPU here. Embedding
  three sentences plus one query takes about 30 ms warm, which is no concern for retrieval. The agent
  LLM (M4) and STT (M5) are where CPU latency will show up. `docker-compose.gpu.yml` is the opt-in.
- Smoke result (nomic-embed-text, cosine): "Do I need a graphics card to run this?" retrieved the GPU
  sentence at 0.609, against 0.417 for the runner-up.
